## 1. 개요

jbTerm은 ConPTY로 자식 프로세스(PowerShell, cmd.exe, WSL 등)를 실행하는 VT220 호환 터미널 프로그램입니다. 256색/트루컬러를 지원하며, 한글 입력/조합 처리를 개선한 것이 특징입니다.

`jbTerm.exe` 하나로 배포되는 단일 파일 프로그램입니다. 기본 설정 값(폰트, 색상, 창 크기 등)이 실행 파일 안에 내장되어 있어서, 별도의 설정 파일 없이 바로 실행할 수 있습니다.



## 2. 실행 방법

인수 없이 실행하면 내장된 기본 설정 그대로 시작합니다. 명령줄 인수는 **앞에서부터 하나씩** 아래 순서로 판정합니다 (`@`/`키=값`/설정파일 인수는 여러 개 조합 가능; 순서 4에 해당하는 인수를 만나는
순간부터는 판정을 멈추고 그 뒤 전부를 통째로 명령행으로 취급합니다).

| 순서 | 인수 형태 | 의미 | 예시 |
|---|---|---|---|
| 1 | `@경로` | 그 경로의 INI 파일을 읽어 설정 위에 덮어씁니다. 여러 개 지정하면 준 순서대로 차례로 적용됩니다. 경로는 현재 작업 디렉토리 기준으로 해석됩니다. | `jbTerm.exe @D:\myset.ini` |
| 2 | `키=값` | 설정 항목 하나를 그 자리에서 바로 지정합니다. | `jbTerm.exe grid_cols=120` |
| 3 | `.ini`/`.txt`/`.jbt`로 끝나는 인수 (대소문자 무관) | `@` 없이도 1번과 동일하게 설정 파일로 적용합니다. | `jbTerm.exe D:\profile-work.ini` |
| 4 | 그 외 | 이 인수부터 **명령줄 끝까지 전부**가 자식 프로세스에 넘길 명령행이 됩니다 (내부적으로 `cmdline=`이 자동으로 붙음). 이 지점 이후의 인수는 `@`나 `=`가 붙어 있어도 더 이상 jbTerm 설정으로 해석되지 않고 자식에게 그대로 전달되는 문자 그대로의 인자입니다. | `jbTerm.exe git commit -m "fix bug"` |

```
jbTerm.exe @D:\profile-work.ini efont_size=14 D:\extra.ini "ssh myuser@myhost"
```

위 예시는 `D:\profile-work.ini`를 먼저 적용하고, 영문 폰트 크기를 14pt로 덮어쓰고, `D:\extra.ini`를
(`@` 없이도) 한 번 더 겹쳐 적용한 뒤, 자식 프로세스로 `ssh myuser@myhost`를 실행합니다.

```
jbTerm.exe myapp.exe @notreal.ini grid_cols=999
```
`myapp.exe`가 명령행 시작이므로, 그 뒤의 `@notreal.ini grid_cols=999`는 jbTerm 설정이 아니라
**`myapp.exe`에 그대로 넘어가는 인자**입니다.

> `@`로 지정하거나(위 1번) `@` 없이 확장자로 인식된(위 3번) INI 파일이 없으면 아무 파일도 만들지 않습니다. 화면에 "파일을 찾을 수 없다"는 안내만 표시하고, 그 인수가 없었던 것처럼(그 전까지 적용된 설정 그대로) 계속 실행합니다.

### 표준입출력(리다이렉션)을 이용한 설정 적용/추출

`cmd.exe`에서(PowerShell은 `<` 리다이렉션을 지원하지 않습니다) 아래와 같이 실행하면 인수 없이도
설정을 적용하거나 추출할 수 있습니다.

| 형태 | 동작 |
|---|---|
| `jbTerm.exe < 설정.ini` | 실행 파일에 내장된 기본 설정을 **아예 적용하지 않고**, `설정.ini`의 내용을 그 자리를 대신하는 기준 설정으로 적용합니다. 그 위에 `@파일`/`키=값` 인수가 순서대로 겹쳐집니다. |
| `jbTerm.exe > 저장.ini` | 이 실행에 최종적으로 적용된 설정(내장 기본값 또는 stdin, + 모든 `@파일`/`키=값` 인수)을 `저장.ini`에 그대로 기록합니다. `@저장.ini`로 다시 불러올 수 있는 형식입니다. |

```
jbTerm.exe < myprofile.ini
```
`myprofile.ini`의 설정이 적용된 채로 이번 실행이 시작됩니다. **`@myprofile.ini`와는 다릅니다**:
`@`는 내장 기본값 위에 `myprofile.ini`를 겹쳐 적용하지만(`myprofile.ini`가 언급하지 않은 항목은
내장 기본값 그대로), `<`는 내장 기본값을 아예 건너뛰므로 `myprofile.ini`가 언급하지 않은 항목은
가장 순정에 가까운 최초 기본값으로 떨어집니다 -- 화면 색상·커서 등 내장 기본값이 따로 손봐둔
항목이라면 결과가 달라질 수 있습니다. `myprofile.ini` 하나만으로 완전한 설정을 구성하고 싶을 때
쓰는 방식입니다.

```
jbTerm.exe < myprofile.ini grid_cols=120 > current.ini
```
`myprofile.ini`를 기준 설정으로 적용한 뒤 `grid_cols=120`으로 한 번 더 덮어쓴 최종 설정을
`current.ini`로 저장합니다(인수가 stdin보다 나중에 적용되므로 `grid_cols`는 `myprofile.ini`에
뭐라고 적혀 있든 120이 됩니다).

실행 파일에 이 설정을 아예 내장해 두고 싶다면(재실행 때마다 `< 설정.ini`를 안 붙여도 되도록), 4장의 "복제본 생성..." 메뉴를 사용하십시오.



## 3. 설정(INI) 항목

`@파일` 이나 새로 만들어지는 INI 파일은 아래와 같은 형태입니다 (섹션 이름은 참고용이며 실제로는
키 이름만으로 인식됩니다).

```ini
[font]
efont_name    = Cascadia Mono   ; 영문 폰트 이름
efont_size    = 12              ; 영문 폰트 크기(pt)
efont_opts    =                 ; B=굵게, I=기울임, 90W=너비 90% 등
kfont_name    = Malgun Gothic   ; 한글 폰트 이름
kfont_size    = 0               ; 0 이하면 영문 폰트 높이에 맞춤
kfont_opts    = B
fallback_font_name = Segoe UI Symbol  ; 글리프가 없는 기호의 대체 폰트

[layout]
margin_top/left/bottom/right = 10   ; 창 가장자리 여백(px)
grid_cols = 96                      ; 가로 칸 수
grid_rows = 32                      ; 세로 줄 수

[window]
start_x / start_y                   ; 시작 위치(px, 가상 화면 좌표). 비워두면 시스템 기본 위치

[screen]
screen_text / screen_back           ; 기본 글자색 / 배경색 (#RRGGBB)
screen_palette00 ~ screen_palette15 ; ANSI 16색 팔레트

[cursor]
cursor_type      = 0   ; 0=기본, 1~6=깜빡/고정 블록·밑줄·I빔
cursor_blink_ms  = 0   ; 0=시스템 설정 따름

[titlebar]
titlebar_caption / titlebar_text / titlebar_border   ; Windows 11 이상에서만 적용

[child]
cmdline         = cmd.exe   ; 실행할 자식 프로세스 명령줄 (비우면 자동 실행 안 함)
work_directory  =           ; 자식 프로세스 작업 디렉토리

[macros]
F1 = 강누리 만세\n     ; F1~F12(F10 제외)를 누르면 그대로 자식에 입력됨

[triggers]
match = password:\x20  ; 화면에 이 문자열이 나타나면
send  = ********\n     ; 자식에게 자동으로 이 문자열을 입력
```

값에 쓰는 이스케이프: `\n`(줄바꿈), `\t`(탭), `\r`(캐리지리턴), `\\`(리터럴 백슬래시, 경로에 쓸 때
예: `C:\\Temp`), `\xHH`(2자리 16진수 바이트, 예: `\x20`=공백). 값 안에 `;`를 그대로 쓰면 그 뒤가
주석으로 잘려나가므로, 리터럴 세미콜론이 필요하면 `\x3b`로 적으십시오.

## 4. 창 조작

**타이틀바 시스템 메뉴** (타이틀바 아이콘 클릭 또는 Alt+스페이스)

| 메뉴 | 동작 |
|---|---|
| 복제본 생성... | 이 실행에 적용된 현재 설정을 그대로 내장한 **새 exe 복사본**을 원하는 경로에 만듭니다(저장 대화상자: 기본 파일명은 실제 exe 이름, 기본 위치는 바탕화면). `< 설정.ini`나 `@파일`/`키=값` 인수를 하나도 안 주고 실행했을 때는 복제해도 지금 실행 파일과 똑같은 내용이 되므로, 이 메뉴 자체와 그 아래 구분선이 나타나지 않습니다. 성공/실패 결과는 타이틀바에 몇 초간 표시됩니다. |
| Text로 저장... | 화면 스크롤백 내용을 텍스트 파일로 저장 |
| EMF로 저장... | 화면 내용을 페이지 단위 EMF 벡터 파일로 저장 |
| PDF로 저장... | 화면 내용을 PDF로 저장 (시스템 PDF 프린터 필요) |
| 기록 시작... / 기록 중지 | 자식 프로세스 원시 출력을 파일로 로깅 시작/중지 |

**마우스**

| 조작 | 동작 |
|---|---|
| 드래그 | 텍스트 선택 → 클립보드 자동 복사 |
| 더블클릭 | 단어 선택 |
| Alt + 드래그 | 직사각형 블록 선택 |
| 파일 드래그 앤 드롭 | 파일 경로를 자식 프로세스로 전송 |
| 휠 | 스크롤 |
| Ctrl + 휠 | 전체 화면 확대/축소 (50%~300%) |

**키보드**

- Enter / Shift+Enter / Ctrl+Enter / Ctrl+J: 각각 CR / LF / LF / LF로 자식에 전달되어, "제출"과 "줄바꿈"을 구분하는 프로그램(Claude Code 등)에서 다르게 동작합니다.
- F1~F12(F10 제외): `[macros]`에 등록된 문자열을 그대로 입력합니다.
- 한글 IME 조합 중 방향키/Enter를 눌러도 조합이 깨지지 않고 순서대로 처리됩니다.

**종료**: 닫기 버튼을 누르면 창은 바로 사라지지만, 뒤에서 자식 프로세스가 정상 종료될 때까지 짧게
기다렸다가(`close_kill_timeout_ms`, 기본 250ms) 완전히 정리됩니다.
